# Bonfire model

Put a bonfire model here as `bonfire.glb` and the site uses it instead of the built-in one.

1. Open https://sketchfab.com/3d-models/dark-souls-bonfire-b0d68c8f4cd0487da3d1fb8327ab1044
2. Sign in, choose **Download 3D Model**, and pick the **GLB** format (the smallest texture size is enough).
3. Save the file as `public/models/bonfire.glb`.

The model is by UselessViking, licensed CC BY 4.0. The footer credits it automatically
when the file is present. Any other `.glb` works too; it is centred and scaled on load.
